## Runtime dependencies

None at runtime. zstd decompression is delegated to the host Node.js runtime.

## Build dependencies

`@types/node`, `typescript`, `tsdown` (build only).

## Host platform

This plugin targets [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (MIT) and, where applicable, [Cordis](https://github.com/cordiverse/cordis). Neither is redistributed here; both are expected to be provided by the host installation.
