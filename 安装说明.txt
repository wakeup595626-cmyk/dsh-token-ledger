【DSH Token 账本插件 · 安装说明】

────────────────────────────────
一、安装前准备
────────────────────────────────
1. 你的电脑是 Windows，并且已经装好 DSH、至少正常启动过一次。
2. 把整个 dsh-token-ledger 文件夹解压到一个「固定不动的目录」，例如：
       D:\dsh-plugins\dsh-token-ledger
   ⚠ 安装完成后不要移动、重命名或删除这个文件夹，否则插件会失效。
3. 安装前请「完全退出 DSH」（连右下角托盘的图标一起退出），
   不要在 DSH 运行的时候安装。

────────────────────────────────
二、一键安装
────────────────────────────────
双击文件夹里的  install.bat

· 脚本会自动找到你的 DSH profile 并安装。
· 如果你的 DSH 有多个 profile，它会列出来，按提示输入编号即可。
· 安装前会自动备份你的 profile 配置（可随时人工回滚）。

────────────────────────────────
三、启动与验证
────────────────────────────────
用你原来的桌面快捷方式重新启动 DSH。启动后：
· 网页右下角会出现「📊 用量」悬浮按钮，点开就是用量统计面板。
· 也可以让 DSH 直接调用  token_ledger_stats  工具查询用量。

────────────────────────────────
四、卸载
────────────────────────────────
双击文件夹里的  uninstall.bat ，然后重启 DSH。
卸载只移除本插件的注册项和链接，不会删除你的账本数据。

────────────────────────────────
五、常见问题
────────────────────────────────
· 双击后闪一下就没了 / 提示被策略阻止：
  在文件夹里按住 Shift 右键 →「在此处打开 PowerShell 窗口」，执行：
      powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Profile web
  把 web 换成你的 profile 名（就是 .dsh\profiles 下面那个文件夹的名字）。

· 提示找不到 profile：
  确认 DSH 已经启动过一次；如果 DSH 装在自定义目录，可加参数 -DshHome "你的DSH根目录"。

· 统计范围：
  只统计 DSH / 模型服务商记录的 usage，不保证所有 API、所有历史记录都被计入，
  也不等同于服务商账单。

· 面板是空的 / 显示「账本 API 不可用」：
  说明插件没被 DSH 加载成功，请检查上面的安装步骤，或看 README.md 的排查说明。

更详细的原理、边界与回滚说明，见同目录的  README.md 。
